# Using ZenMux With Kilo Code

ZenMux provides a unified API gateway for accessing models from multiple AI providers through a single API.

**Website:** [https://zenmux.ai/](https://zenmux.ai/)

## Getting an API Key

1.  **Sign Up/Sign In:** Go to the [ZenMux website](https://zenmux.ai/). Sign up for an account.
2.  **Get an API Key:** Go to your ZenMux dashboard to generate an API key.
3.  **Copy the Key:** Copy the API key.

## Configuration in Kilo Code

1.  **Open Kilo Code Settings:** Click the gear icon ({% codicon name="gear" /%}) in the Kilo Code panel.
2.  **Select Provider:** Choose "ZenMux" from the "API Provider" dropdown.
3.  **Enter API Key:** Paste your ZenMux API key into the "ZenMux API Key" field.
4.  **Select Model:** Choose your desired model from the "Model" dropdown.
5.  **(Optional) Custom Base URL:** If you need to use a custom base URL for the ZenMux API, check "Use custom base URL" and enter the URL. Leave this blank for most users.

## Tips and Notes

- **Model Selection:** Check the [ZenMux models page](https://zenmux.ai/models) for available models.
- **Configuration:** Use the custom base URL option if you need to use a specific API endpoint.
